# 客户端回归检查

运行：

```powershell
dotnet run --project tests/MioReel.RegressionTests
```

覆盖历史文件重载、去重、删除、清空、损坏恢复、真实进度保存和断点续播，以及下一集预加载复用、失败重试、画质切换、跳集和关闭取消。

片库检查覆盖首屏重复、跨页重叠、自动预取和加载更多交错、连续加载、刷新期间旧请求返回、两屏预加载阈值，以及列数变化后的列表一致性。自动预取由新的滚动操作授予一次加载机会；列表增长和停留在底部不会反复触发加载，刷新后恢复初始加载机会。

播放检查还覆盖直接替换播放源、播放开始后释放旧会话、默认画质变更、单集降级不覆盖后续画质偏好、1080P 变体选择、上下集边界和标题总集数。位置检查覆盖大小窗独立记录、设置更新后保留记录，以及不同显示器和缩放比例下的可见区域调整。

历史保存在 `%LOCALAPPDATA%\MioReel\history.json`，最多保留 500 部短剧。播放时每 5 秒保存进度，关闭、切集和切换画质时也会保存。下一集提前准备播放会话、开头约 2 MiB 数据和尾部约 256 KiB 数据；关闭、跳集或切换画质时释放不再使用的缓存。大小窗位置和尺寸分别保存在 `settings.json` 的 `normalWindow`、`miniWindow` 中。

媒体缓存检查使用本地 TCP Range 服务，验证开头和尾部直接命中缓存、文件尾部探测不淘汰开头缓存，以及会话释放。无需连接视频网关，不启动客户端 UI。

离线下载检查覆盖真实文件落盘和逐字节完整性、暂停继续、已完成分集复用、任务重启恢复、失败重试、目录变更、路径隔离、本地文件丢失，以及不连接网关的本地播放和切集。倍速检查覆盖设置落盘、重新创建播放器后的选中状态，以及打开视频和切集时保留倍速。

在播放页点击“缓存”选择下载前 20 集或全部剧集。在“设置 → 存储与服务 → 离线下载目录”点击“更改目录”选择文件夹，仅新任务使用新目录。任务记录保存在 `%LOCALAPPDATA%\MioReel\downloads.json`，下载按队列串行执行，完成后从“离线下载 → 已完成 → 立即观看”播放本地 MP4。暂停或重启后继续会复用完整分集，尚未完成的单集重新下载；重启后未完成任务保持暂停。移除任务保留本地文件。

小窗交互回归需启动客户端：按住播放按钮或拖动进度条时将鼠标移出窗口，工具栏应保留至交互结束；释放后鼠标仍在窗口外时，工具栏延迟约 200 毫秒隐藏。快速移出再移入不应中断按钮点击，倍速和清晰度菜单打开期间也不应隐藏工具栏。分别检查悬浮工具栏和 NativeSurface 停靠工具栏。

客户端已在运行而输出文件被占用时，可使用独立输出目录：

```powershell
dotnet run --project tests/MioReel.RegressionTests -p:OutputPath=bin/Verification/
```
